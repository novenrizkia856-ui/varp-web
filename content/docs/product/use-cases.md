# Use Cases

## Wallets

Before displaying or deeply integrating a token, a wallet can ask:

> What rights and restrictions does this asset have?

The wallet can use Varp to surface transfer restrictions, verification state, or redemption information.

## DeFi Protocols

Before accepting an asset as collateral or allowing it in a pool, a protocol can ask:

> Can this token actually interact with the protocol, and are there restrictions?

Varp can expose permission requirements and contract level limitations.

## Exchanges

Before listing or presenting a token, an exchange can ask:

> What does this token represent and what restrictions apply?

## Asset Issuers

Issuers can publish or reference a standardized machine readable rights profile instead of requiring every integrator to interpret documents independently.

## Developers

Developers can query one schema instead of building a custom research process for every tokenized asset.

## Users

Users can answer the most basic question:

> What does this token actually give me?
